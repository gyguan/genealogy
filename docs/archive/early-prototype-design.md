# 早期原型设计（已归档）

> 状态：历史资料。本文描述 `prototype/` 中的早期 HTML 演示，不代表当前 React 正式前端规范。当前页面与交互规则见 `docs/frontend/design-system.md` 和 `docs/frontend/page-patterns.md`。

## 原型目标

早期 MVP 1 原型用于演示管理端核心闭环：工作台、宗族管理、支派管理、字辈管理、人物管理、关系维护、来源绑定、审核中心、世系图、导入导出、权限管理。

## 信息架构

```text
首页工作台
├── 数据概览
├── 待审核事项
└── 快捷入口

宗族管理
支派管理
字辈管理
人物管理
世系图
资料来源
审核中心
导入导出
权限管理
系统日志
```

## 核心页面

| 页面 | 说明 |
|---|---|
| 首页工作台 | 展示总人数、支派数、待审核、资料来源、最近修改 |
| 宗族管理 | 维护宗族名称、姓氏、堂号、郡望、始祖、简介 |
| 支派管理 | 左侧支派树，右侧支派详情和成员统计 |
| 字辈管理 | 维护派语、世次映射和校验规则 |
| 人物列表 | 支持按姓名、支派、世次、字辈、状态筛选 |
| 人物详情 | 展示基础档案、亲属关系、传记、来源和修订记录 |
| 关系编辑 | 维护父母、配偶、子女、继嗣、出嗣等关系 |
| 世系图 | 支持家庭图、上溯图和下延树 |
| 资料来源 | 上传资料并绑定人物或关系 |
| 审核中心 | 待审核列表、变更对比、通过和驳回 |
| 导入导出 | 上传 Excel、校验错误、确认导入草稿 |
| 权限管理 | 邀请成员、分配角色、设置支派范围 |

## 历史入口

prototype/index.html

## 仍然有效的产品原则

1. 人物录入应支持高效维护家庭关系。
2. 正式数据不能直接修改，必须形成修订和审核。
3. 世系图默认限制代数和节点规模，按需展开。
4. 资料来源应与人物、关系等业务对象建立可追溯绑定。
