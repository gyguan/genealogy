# 早期产品 Roadmap（已归档）

> 状态：历史规划。本文保留项目早期阶段划分，不代表当前交付计划。当前优先级、范围和完成状态以 GitHub Issues、Milestones、Pull Requests 及已批准 Spec 为准。

## MVP 1：核心建谱闭环

目标：让一个宗族完成基础建谱、人物录入、关系维护、来源绑定、审核流转、世系查看、基础导入导出和权限隐私闭环。

主要方向：

- 宗族、支派和字辈管理；
- 人物档案和关系管理；
- 来源证据和审核中心；
- 世系图；
- Excel 导入导出；
- 宗族成员、角色、支派范围、隐私级别和操作日志。

## MVP 2：协作修谱与数字化增强

早期规划方向：

- 族人邀请和在线填报；
- 批量审核与更完整的变更历史；
- 老谱图片与 OCR；
- 重复人物合并；
- 支派任务分发；
- 生者信息保护、附件权限和导出审批。

## MVP 3：智能寻祖与谱书出版

早期规划方向：

- AI 人名和关系候选识别；
- 寻祖路径和迁徙展示；
- 五服关系计算；
- 谱书编排与 PDF 输出；
- 宗亲社区、活动和公告；
- 更细粒度授权与权限审计。

## 长期愿景

```text
族谱数据底座
  → 协作修谱平台
  → 老谱数字化中心
  → 谱书出版平台
  → 宗亲知识服务平台
```

本文只用于理解早期产品方向，不应用作 Issue 验收、发布日期或实施顺序依据。
