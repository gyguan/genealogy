# 历史文档归档

本目录保存已经结束、被替代或仅用于追溯的设计与交付资料。归档文档不是当前规范、验收标准、接口契约或开发计划。

## 分类

- `delivery/`：已完成 Issue、Slice、重构方案和收口记录。
- `prototypes/`：已被正式实现替代的页面和交互原型。
- `testing/`：阶段测试报告、准出结论和一次性执行记录。
- 本目录根文件：早期产品 Roadmap、原型总览等历史材料。

## 使用原则

- 查找当前规则时不要默认读取 Archive；
- 只有追溯历史决策、兼容来源或变更背景时才读取；
- Archive 中的接口字段、目录结构、状态和计划可能已经失效；
- 当前权威入口见 `docs/README.md` 和 `docs/standards/README.md`；
- 新增归档文件时，文件名应表达主题，路径应表达历史类型，避免继续使用无上下文的编号名称。

## 删除条件

归档内容在以下情况下可以继续删除：

1. 已无历史决策、审计或兼容价值；
2. 只是重复的执行看板状态，没有独立结论；
3. 对应信息已由 GitHub Issue、PR、Release 或 Git 历史完整保存；
4. 内容包含不应长期保留的敏感或环境信息。
