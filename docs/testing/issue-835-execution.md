# Issue #835 执行记录

## 目标

验证正式数据在族谱首页、人物档案、世系图谱、来源资料库、宗族文化和审计追踪中的查询展示、状态和权限一致性。

## 核心链路

```text
正式人物/关系/来源/文化数据发布
→ 首页统计变化
→ 人物列表、分页、排序和详情深链接
→ 来源列表与详情深链接
→ 世系上溯/下延结果
→ 宗族文化列表与详情
→ 审计追踪 before/after、Revision、Task 和操作者
→ 浏览器刷新、前进后退恢复
→ 支派范围与跨宗族查询不泄漏对象、数量和摘要
```

## 必测用例

- FT-QUERY-001：首页统计与正式人物/支派/来源一致；
- FT-QUERY-002：人物查询条件、分页、排序与 URL 恢复；
- FT-QUERY-003：人物详情深链接与浏览器前进后退；

- FT-SOURCE-001：来源列表、详情和对象绑定一致；
- FT-TREE-001：世系上溯、中心人物与下延结果一致；
- FT-CULTURE-001：文化总览、列表、详情和首页精选一致；
- FT-AUDIT-001：对象、Revision、Review Task、Diff 和操作者可追溯；
- FT-AUDIT-002：无权限与不存在对象的 403/404 语义正确；
- FT-SCOPE-001：支派范围账号不泄漏兄弟支派对象、数量和摘要；
- FT-SCOPE-002：跨宗族查询不泄漏对象、数量和摘要。

## 当前发现

- 首页 Dashboard 当前只校验账号拥有 `person:view`，后续人物、支派、来源、审核统计均按全宗族聚合；
- 对支派子树角色可能泄漏兄弟支派数量、分布和最近活动；
- 文化列表、文化详情和文化总览自身已按角色、支派与隐私范围构造查询。
