## 2. #828 整改验证

#828 已完成：

- 后端审核服务在批准和驳回前校验提交人与审核人隔离；
- 稳定错误码：`REVIEW_SELF_DECISION_FORBIDDEN`；
- 单元测试验证 approve/reject 均拒绝自审；
- PostgreSQL 集成测试验证失败后 Review Task、Revision 仍为 `pending`；
- 真实浏览器测试验证提交人自审失败、独立审核员审批成功、宗族正式生效；
- 未依赖前端隐藏按钮，也未使用 `continue-on-error` 或删除断言。

## 3. 当前未关闭的功能覆盖风险

以下内容未纳入本次 P0 代表性真实 E2E，不应被理解为已完成发布准出：

| 优先级 | 范围 | 建议补充的测试 |
|---|---|---|
| P0 | 字辈、人物、关系、来源完整审核链 | UI 提交、审核中心处理、正式数据生效、驳回与重提 |
| P0 | 数据导入 | 预览、错误行修正、事务回滚、重试、幂等和重复导入 |
| P1 | 附件与来源文件 | 上传、预览、下载、格式限制、对象存储失败和权限隔离 |
| P1 | 修谱工作台 | 任务领取、批量处理、冲突刷新和并发修改 |
| P1 | 审核中心 | 批量审批、质量门禁、重复提交和过期任务 |
| P1 | 谱册导出 | 文件内容、格式、权限和大数据量导出 |
| P1 | 深层世系 | 大节点数、深层递归、截断告警和响应时间 |
| P2 | 浏览器与终端 | Firefox、WebKit、移动端和真机兼容 |
| P2 | 非功能专项 | 性能、安全、可访问性、视觉回归和灾备恢复 |

## 4. 准出边界

本次可确认：

- 真实 PostgreSQL/Flyway 测试基础设施可运行；
- 真实前后端浏览器流水线可重复执行；
- 登录、首次建谱、刷新持久化、深链接、审核隔离、独立审批、三代世系和两类跨宗族权限已通过；
- 失败日志、Trace、截图、视频和测试报告可追踪。

本次不能确认：

- 全菜单、全角色、全业务场景均已覆盖；
- 已完成生产性能、安全和容量准出；
- 所有浏览器和移动设备均无兼容问题。

## 5. 建议处理方式

遗留项不阻断 #812 测试体系建设验收，但应在对应业务模块发布前转化为独立测试 Issue，并将新增 P0 用例接入同一 `Functional E2E` 门禁。
