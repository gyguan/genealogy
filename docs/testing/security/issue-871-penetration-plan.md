# Issue #871 专业安全渗透测试方案

## 授权与边界

本测试仅针对 `gyguan/genealogy` 的隔离 CI 环境和测试数据执行。禁止扫描未授权公网目标、生产数据或第三方系统。发生异常时停止测试并保留 Actions 日志与 Artifact。

## 威胁角色

- 未认证外部攻击者；
- 持有畸形或过期凭证的攻击者；
- 已登录低权限用户；
- 其他宗族的合法用户；
- 尝试利用输入、文件和错误响应的恶意用户。

## 自动化范围

### 静态与供应链

- Trivy 文件系统扫描；
- 操作系统包、Maven、npm 与配置文件中的 CRITICAL/HIGH 已知漏洞；
- 私钥、令牌和敏感配置暴露；
- SARIF 与 Artifact 归档。

### 动态攻击面

- 匿名访问与畸形 Bearer Token；
- Session、CSRF 和注销后令牌重放；
- 跨宗族水平越权与响应体数据泄漏；
- SQL 注入探针及数据库诊断泄漏；
- 路径遍历与双重编码；
- 账号枚举；
- 非法 JSON、堆栈和框架信息泄漏；
- `nosniff`、防点击劫持和缓存响应头；
- `.exe`、SVG 脚本等危险文件上传；
- 后端日志中的密码、访问令牌和私钥泄漏。

## 风险分级

- Critical：可直接接管系统、批量获取敏感数据或执行任意代码；
- High：认证绕过、跨宗族数据泄漏、危险文件可执行或稳定利用的注入；
- Medium：需要复杂前提的信息泄漏、弱安全头或局部业务绕过；
- Low：安全加固建议和低影响配置问题。

## 阻断规则

- Critical/High 未修复数量必须为 0；
- 任一动态安全控制失败，阻断合并；
- Trivy CRITICAL/HIGH 且有修复版本时，阻断合并；
- 不得出现未授权访问、跨宗族标记泄漏、SQL 堆栈、系统文件读取、危险文件接受或注销后凭证继续有效。

## 证据

报告必须包含 Commit、Run、环境、工具版本、请求与响应头体、测试清单、分级、修复结论、Artifact ID 和 SHA-256。

## 结论边界

本门禁属于可重复执行的工程渗透基线，覆盖代码与隔离运行环境的主要攻击面。独立第三方人工渗透、社会工程、云平台配置、WAF/CDN、生产网络和移动端不在本 CI 门禁内，不能用自动化扫描替代其正式资质报告。
