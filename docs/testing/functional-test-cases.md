## 7. 执行与报告规则

每次自动化执行必须记录：

- 用例编号；
- Commit SHA；
- 测试环境和数据库版本；
- 执行结果：通过、失败、阻断、未执行；
- 失败日志、Trace、截图或 SQL 证据；
- 关联缺陷 Issue；
- 回归结果。

P0 用例不得通过 `skip`、删除断言、放宽权限或固定长等待制造通过。
