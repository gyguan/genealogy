# Issue #832 执行记录

## 目标

验证审核治理从提交、Diff、驳回、修改、重提到批准，以及并发处理和批量部分冲突的完整闭环。

## 业务链

```text
编辑者创建人物
→ 提交审核
→ 审核员查看任务与字段 Diff
→ 驳回并填写原因
→ 正式数据不生效
→ 编辑者修改人物与事件
→ 重新提交
→ 独立审核员批准
→ 人物正式生效
→ 审核记录保留两次 Revision
```

## 并发与批量场景

- 同一任务并发批准：最多一次成功；
- 已处理任务再次批准：稳定拒绝；
- 模拟批量处理时，一个已处理任务失败、一个待处理任务成功；
- 每个目标对象最终状态与任务结果一致。
