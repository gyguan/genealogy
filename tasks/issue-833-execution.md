# Issue #833 执行记录

## 目标

验证人物与人物关系批量导入从真实文件预览、混合行处理、错误修正、重试、审核发布到同文件幂等的完整业务链。

## 人物导入链

```text
真实 CSV 上传
→ 预览有效/非法/疑似重复行
→ 未确认重复时阻断
→ 确认后创建人物草稿与失败行
→ 仅修正失败行
→ 旧版本/成功行禁止重复重试
→ 批次进入 ready_for_review
→ 独立审核员批准
→ 人物正式发布
→ 相同内容文件改名重传仍返回原 jobId
```

## 关系导入链

```text
建立正式人物编码基线
→ 真实关系 CSV 预览
→ 有效关系创建草稿
→ 人物不存在与文件内重复行失败
→ 分行修正为新的合法关系
→ 批次审核批准
→ 父子/配偶关系正式生效
→ 相同内容文件重传返回原 jobId
```

## 缺陷与修复

- #844：同一文件重复提交会重复创建批次和业务草稿；
  - 新增文件 SHA-256 指纹；
  - 以宗族、支派、导入类型和文件内容建立唯一映射；
  - 重复文件直接返回原批次，数据库唯一约束兜底。
- #847：人物导入首次返回缺失处理与审核状态；
  - 统一由幂等边界重新加载完整批次 DTO；
  - 首次提交与重复提交返回同一完整契约。
